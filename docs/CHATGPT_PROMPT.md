# ChatGPT Prompt for App Store Assets

Copy and paste this prompt into ChatGPT (or Claude, or another AI design tool):

---

## Prompt

I need you to create professional App Store assets for my mobile app "Overtime+". This is a healthcare shift tracking application for healthcare professionals to track their work shifts and overtime, with automated PDF form generation.

### App Overview
- **Name:** Overtime+
- **Purpose:** Track shifts and overtime securely across devices, with automated AVAC (Attendance Variation and Allowance Claim) PDF form generation
- **Target Audience:** Healthcare professionals, particularly those working in Queensland Health facilities

### Design System

**Color Palette:**
- Primary Blue: #2563EB (main brand color)
- System Blue: #007AFF (iOS system blue, used for accents)
- Success Green: #10B981 and #4CAF50
- Warning Orange: #FFA500
- Background (Light): #FFFFFF and #F5F5F5
- Background (Dark): #000000 and #1C1C1E
- Text (Light): #111111, #333333, #666666
- Text (Dark): #FFFFFF, #AAAAAA, #999999

**Typography:**
- Uses system fonts (San Francisco on iOS, Roboto on Android)
- Font weights: 300, 400, 500, 600, 700, 800
- Font sizes: 11px to 48px (body text typically 14-16px, titles 26-48px)

**Design Style:**
- Clean, modern, professional
- Card-based UI with rounded corners (12-16px radius)
- Subtle shadows for depth
- Healthcare-focused, trustworthy appearance
- Full dark mode support

### Required Assets

1. **App Icon**
   - iOS: 1024x1024px PNG (no transparency, no rounded corners)
   - Android: 512x512px PNG (no transparency)
   - Should include "Overtime+" name or recognizable logo
   - Consider incorporating time/clock elements or a stylized "+" symbol
   - Professional, healthcare-appropriate aesthetic
   - Use primary blue (#2563EB or #007AFF) as main color

2. **Google Play Feature Graphic**
   - 1024x500px PNG or JPG
   - Horizontal banner for Play Store listing
   - Include app name and key value proposition
   - Use brand colors (blue primary)
   - Text should be readable at small sizes

3. **Screenshot Mockups** (showing app interface)
   - iPhone 6.7": 1290x2796px
   - iPhone 6.5": 1242x2688px
   - iPhone 5.5": 1242x2208px
   - iPad Pro 12.9": 2048x2732px
   - Android phone: Various sizes (16:9 or 9:16 aspect ratio)
   - Show key screens: Home screen with shift tracking, log entry, analytics, export screen

### Design Guidelines

- **Logo/Icon Style:** Modern, geometric, professional
- **Color Usage:** Blue as primary, use sparingly but prominently
- **Text:** Bold, readable, minimal text on graphics
- **Imagery:** Consider subtle healthcare/time-tracking iconography
- **Consistency:** Use same color palette and design language throughout
- **Accessibility:** Ensure sufficient contrast (WCAG AA minimum)

### Key Features to Highlight
- Secure shift and overtime tracking
- Automated PDF form generation
- Offline-first with cloud sync
- Quick log entry
- Analytics and insights
- Dark mode support

### Tagline Options
- "Track shifts and overtime securely across devices"
- "Automated overtime tracking for healthcare professionals"
- "Simplify your shift tracking and AVAC forms"

Please create these assets following the specifications above. The design should be professional, modern, and trustworthy - appropriate for healthcare professionals. Use the blue color palette as the primary brand color, and ensure all text is readable and accessible.

## Tips for Using This Prompt

1. **Start with the icon:** Ask ChatGPT to create the app icon first, then iterate based on feedback
2. **Request variations:** Ask for multiple versions (light background, dark background, monochrome)
3. **Specify format:** Remind ChatGPT to export as PNG with no transparency for icons
4. **Iterate:** Don't expect perfect results on first try - refine based on output
5. **Check dimensions:** Verify all assets match the specified dimensions
6. **Test readability:** Ensure text is readable at small sizes (especially for feature graphic)
